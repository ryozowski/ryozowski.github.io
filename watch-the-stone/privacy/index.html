基本方針

石を見守る（以下「本アプリ」）は、本ポリシーに定める範囲で利用者の情報を取得し、定めた目的にのみ利用します。

本アプリの見守り・図鑑の機能は、すべて端末内で完結します。本アプリの開発者はサーバーを運用しておらず、利用者のデータを受け取る仕組みを持っていません。

本アプリが通信を行うのは、画面下部に表示する広告を取得するときだけです。広告は Google の広告配信サービス（Google AdMob）が配信し、その際に広告の SDK が後述の情報を Google へ送信します。

収集する情報と利用目的

本アプリの開発者が利用者の情報を直接取得することはありません。以下は、本アプリに組み込んだ広告の SDK（Google Mobile Ads SDK）が自動的に取得し、Google へ送信する情報です。

取得する情報取得方法利用目的送信先
IP アドレス（おおよその地域の推定に使われます）自動取得広告の配信、広告の効果の測定、不正の防止Google（Google AdMob）
端末の情報（OS の種類・バージョン、端末の機種など）自動取得広告の配信、広告の効果の測定、不正の防止Google（Google AdMob）
広告の表示・タップなどの操作自動取得広告の配信、広告の効果の測定、不正の防止Google（Google AdMob）
診断情報（広告の読み込みの成否・パフォーマンス・クラッシュの情報）自動取得広告の SDK の不具合の調査と改善Google（Google AdMob）
App Set ID（Android のみ。同じ開発者のアプリの間で使われる識別子）自動取得広告の効果の測定、不正の防止Google（Google AdMob）

取得した情報は上記の目的以外には利用しません。Google による情報の保存期間と取り扱いは、Google のプライバシーポリシーに従います。

本アプリは次の方針で広告を表示しています。

  • 広告は 非パーソナライズ広告 に限ります。利用者の興味・関心に基づく広告（パーソナライズ広告）は要求しません
  • Android 版は、広告 ID（Advertising ID）と Privacy Sandbox（広告 ID・アトリビューション・トピック）の権限をアプリから取り除いており、広告 ID を送信しません
  • iOS 版は、トラッキングの許可（App Tracking Transparency）を求めません。そのため広告識別子（IDFA）は取得されません
  • 欧州経済領域（EEA）・英国・スイスでは、同意の取得を行わず、Google の「限定広告」（パーソナライズのための個人データを使わず、端末の識別子を使わない広告）だけが配信されます

端末内に保存する情報

以下は本アプリの機能のために、利用者の端末内にのみ保存されます。本アプリの開発者に送信されることはありません。

保存するもの用途
図鑑の観測記録（観測した変化の種類・観測回数・初めて / 最後に観測した日時）図鑑を表示するため
音のオン / オフの設定設定を次回起動時に引き継ぐため
見守りの途中の状態（見守っている対象と、その時点までの見つめ時間）OS がアプリを一時的に終了したときに、続きから再開するため（OS の状態復元の仕組みを使い、一時的にだけ保持します）

これらはアプリのアンインストールによって端末から削除されます。

これらのデータは、OS のバックアップ機能（iCloud バックアップ / Android の自動バックアップ）の対象になる場合があります。バックアップから新しい端末に復元した場合、図鑑の観測記録は引き継がれます。これは OS の機能によるもので、本アプリの開発者が受け取るものではありません。

端末の権限

本アプリは、利用者に許可を求める権限（カメラ・写真・位置情報・通知・マイク・連絡先など）を使いません。起動時を含め、権限の許可を求めるダイアログは表示しません。

Android 版は、広告の取得のためにインターネット接続などの権限（INTERNET / ACCESS_NETWORK_STATE など、利用者の許可を必要としないもの）を宣言しています。

外部サービスの利用

本アプリは以下の外部サービスを利用しています。各サービスによる情報の取り扱いは、提供元のプライバシーポリシーをご確認ください。

サービス提供元用途送信される情報提供元のプライバシーポリシー
Google AdMob（Google Mobile Ads SDK）Google LLC広告の配信「収集する情報と利用目的」に記載した情報https://policies.google.com/privacy

Google による広告での情報の使い方は、https://policies.google.com/technologies/partner-sites でも説明されています。

第三者への提供

取得した情報は、法令に基づく場合、および「外部サービスの利用」に記載したサービスへの送信を除き、利用者の同意なく第三者へ提供しません。本アプリの開発者は、情報を送信するサービスの提供元が本ポリシーと同等以上の保護を行っていることを確認したうえで利用します。

「外部サービスの利用」に記載した提供元には、日本国外（アメリカ合衆国）の事業者が含まれます。アメリカ合衆国における個人情報の保護に関する制度は、個人情報保護委員会の「外国制度（アメリカ合衆国）」（https://www.ppc.go.jp/enforcement/infoprovision/laws/offshore_report_america/）を、提供元が講じている措置は、Google のプライバシーポリシーをご確認ください。

安全管理措置

本アプリの開発者はサーバーを運用しておらず、利用者の情報を保有しません。広告の SDK による Google への送信は、暗号化された通信（TLS）で行われます。

データの削除

利用者は以下の方法でデータを削除できます。

  • 本アプリをアンインストールする（端末内のすべてのデータが削除されます）

Google が保有する情報の管理・削除は、Google のアカウントの設定や、Google のプライバシーポリシーに記載された方法で行えます。

開示・訂正・利用停止等の請求

本アプリの開発者は利用者の情報を保有していないため、開示・訂正・削除などの対象となる情報はありません。ご不明な点は、下記のお問い合わせ先までご連絡ください。Google が保有する情報についての請求は、Google のプライバシーポリシーに記載された方法で行えます。

子どものプライバシー

本アプリは一般向け（13 歳以上を想定）のアプリです。13 歳未満の子どもの情報を意図して取得することはありません。子どもの情報が取得されたことに保護者の方が気付いた場合は、下記のお問い合わせ先までご連絡ください。

本ポリシーの変更

本ポリシーを変更する場合は、本ページの内容を更新し、最終更新日を改めます。重要な変更がある場合はアプリの更新情報でお知らせします。
