基本方針

偽電話（以下「本アプリ」）は、利用者の個人情報および利用データを収集しません。 本アプリの開発者はサーバーを運用しておらず、利用者のデータを受け取る仕組みを持っていません。

偽連絡先・スケジュール・画像・音声ファイルを含むすべてのデータは利用者の端末内に保存され、 本アプリがこれらを外部のサーバーや第三者へ送信することはありません。

本アプリがネットワークに接続するのは、次の 2 つの場合に限られます。

  • プレミアムの購入・購入の復元を行うとき（App Store / Google Play との通信。後述）
  • アプリ内でこのプライバシーポリシーや利用規約を表示するとき（本ページの読み込み。後述）

なお、利用者が端末のバックアップ（iCloud バックアップや Google のバックアップ）を利用している場合、 他のアプリと同様に本アプリのデータもそのバックアップに含まれます（後述）。これは OS の機能に よるもので、本アプリが送信しているものではありません。

収集しない情報

本アプリは以下の情報を 取得も送信もしません。

  • 氏名・メールアドレス・電話番号などの、利用者本人を識別できる情報
  • 端末の識別子（IDFA / 広告 ID / IMEI 等）
  • 位置情報
  • 端末の連絡先・カレンダー・通話履歴などの、他のアプリのデータ
  • カメラの映像・マイクの音声
  • アプリの利用状況・クラッシュログ・アクセス解析などの統計情報

本アプリには解析 SDK・広告 SDK を組み込んでいません。広告も表示しません。

偽連絡先として登録する発信者名や電話番号は、利用者が着信画面に表示するために任意に入力する 架空の情報であり、端末内にのみ保存されます。

端末内に保存する情報

以下は本アプリの機能のために、利用者の端末内にのみ保存されます。

保存するもの用途
偽連絡先（発信者名・電話番号・アイコン画像・着信音・着信画面の種類・通話時間・背景画像・最後に使った日時）着信画面を再現するため
偽着信のスケジュール（予約時刻・リピート・ランダムな遅れの設定）予約した時刻に着信させるため
カスタム着信音・カスタム音声ファイル（プレミアム）利用者が選んだ音声を再生するため
設定値（言語・既定の着信画面・既定の着信音・着信時の挙動・初回説明の完了・通知の許可状態）設定を次回起動時に引き継ぐため
プレミアムの購入状態購入済みの機能を利用できるようにするため
最近使った偽連絡先の名前とアイコン（名前は最大 4 件）ホーム画面ウィジェットの表示と、アプリアイコンのショートカットに使うため

最後の項目は、アプリとウィジェットが共有する端末内の領域（iOS の App Group など）と、OS のショートカット機能に 登録されます。端末の外へ送信されることはありません。

これらはアプリのアンインストールによって端末から削除されます。

これらのデータは端末のバックアップ（iCloud バックアップや Google のバックアップ）の対象になります。 アプリを再インストールしたときや、バックアップから新しい端末に復元したときに、データが引き継がれることがあります。

画面に表示される情報について

次の場所には、登録した発信者名とアイコンが表示されます。

  • 着信画面（ロック画面の上に表示されることがあります）
  • 予約した着信の通知
  • ホーム画面ウィジェット
  • アプリアイコンを長押ししたときのショートカット

これらは端末の画面に表示されるだけで外部へ送信されることはありませんが、 周囲の人から見える場合があることにご注意ください。

端末の権限の利用

本アプリは以下の権限を、それぞれの目的のためだけに利用します。

権限対象用途
通知iOS / Android予約した時刻に着信の通知を表示するため
正確なアラームAndroid端末のスリープ中でも予約した時刻どおりに通知するため
全画面通知Android着信を画面全体に表示するため
バイブレーションAndroid着信時に振動させるため
起動完了の受信Android端末の再起動後に、予約済みの着信を登録し直すため
写真ライブラリiOS利用者が発信者アイコンや背景画像を選ぶため
インターネット接続Androidアプリ内でプライバシーポリシー・利用規約を表示するため（後述）

このほか Android 版には、組み込んでいるライブラリが宣言する権限（ネットワーク状態の確認、スリープの抑止、 バックグラウンド処理、Google Play の課金）が含まれます。 本アプリがこれらを使って情報を送信することはありません。

写真ライブラリへのアクセスは、利用者が画像を選ぶ操作をしたときだけ求めます。Android では OS の画像選択画面を 利用するため、写真ライブラリ全体へのアクセス権限は要求しません。カスタム着信音などの音声ファイルも、 OS のファイル選択画面で利用者が選んだファイルだけを読み込みます。

Android では、着信音を鳴らすかどうかを決めるために端末のマナーモードの状態を読み取ります。 この判定は端末内で行い、結果を送信することはありません。

いずれの権限も、拒否した場合はその機能だけが使えなくなり、他の機能は利用できます。

プレミアムの購入

プレミアムの購入と購入の復元は、App Store（Apple Inc.）または Google Play（Google LLC）を通じて行われます。 決済に関する情報は各社が処理し、本アプリの開発者が利用者の Apple ID・Google アカウント・支払い手段の 情報を受け取ることはありません。本アプリは、購入が完了したかどうかの結果だけを受け取り、端末内に保存します。

各社による情報の取り扱いは、それぞれのプライバシーポリシーをご覧ください。

  • Apple のプライバシーポリシー
  • Google のプライバシーポリシー

アプリ内でのポリシーの表示

アプリの設定画面からこのプライバシーポリシーや利用規約を開くと、本アプリは本ページ （GitHub Pages で公開しています）を読み込みます。このとき、一般的なウェブサイトの閲覧と同様に、 GitHub が IP アドレスなどのアクセス情報を記録することがあります。本アプリの開発者がこの情報を 受け取ることはありません。詳しくは GitHub のプライバシーステートメント をご覧ください。

第三者への提供

本アプリは利用者の情報を収集しないため、第三者へ提供する情報はありません。

データの削除

利用者は以下の方法でデータを削除できます。

  • 偽連絡先・スケジュール・カスタム着信音・カスタム音声ファイルを、それぞれの画面から個別に削除する
  • 設定画面の「すべてのデータを削除」で、偽連絡先・スケジュール・カスタム着信音・カスタム音声ファイルをまとめて削除する（プレミアムの購入状態と、言語などの一部の設定は残ります）
  • 本アプリをアンインストールする（端末内のすべてのデータが削除されます）

子どものプライバシー

本アプリは年齢に関わらず利用できますが、いかなる利用者からも個人情報を収集しません。

本ポリシーの変更

本ポリシーを変更する場合は、本ページの内容を更新し、最終更新日を改めます。 重要な変更がある場合はアプリの更新情報でお知らせします。
