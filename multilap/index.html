マルチラップ計測

MULTILAP

複数人のラップタイムを、1 台のスマートフォンで同時に計測するストップウォッチアプリです。 1 人分の計測を「カード」として扱い、カードごとに独立したストップウォッチが動きます。

主な機能

  • カードごとの独立した計測と、画面内の全カードへの一括 Start / Stop / Lap / Reset
  • カードをまとめる「グループ」単位での一括操作
  • 用途に応じた 3 つの画面（標準・ミニ・リッチ）
  • 目標ラップ数の設定と到達表示
  • 最速ラップ・最遅ラップの自動判定
  • 計測結果の保存と、CSV / テキスト形式での共有
  • カード構成をテンプレートとして保存・呼び出し
  • 日本語 / 英語、ダークテーマ / ライトテーマ

よくある質問

アプリを閉じたり画面がロックされたりしても計測は続きますか？

続きます。経過時間は開始時刻からの差分で算出しているため、アプリを閉じた場合や、アプリが強制終了された場合でも、再度開いたときに正しい時間が表示されます。

計測データはどこに保存されますか？

すべて端末内に保存されます。本アプリはネットワーク通信を行わず、本アプリがデータを外部のサーバーへ送信することはありません。詳しくはプライバシーポリシーをご覧ください。

機種変更したらデータは引き継がれますか？

Android では引き継がれません。自動バックアップや端末間データ転送の対象から除外しているためです。iOS では端末のバックアップを利用している場合、データはそのバックアップに含まれ、復元やクイックスタートで引き継がれます。確実に残したい計測結果は、事前に CSV またはテキストとして共有・保存してください。

計測結果を書き出せますか？

共有シートから CSV 形式またはテキスト形式で書き出せます。進行中の現在ラップも含めて出力されます。

カードやラップはいくつまで作れますか？

カードは画面種別ごとに 50 枚（3 画面で合計 150 枚）、ラップは 1 カードにつき 999 本までです。
