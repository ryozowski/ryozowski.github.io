基本方針

マルチラップ計測（以下「本アプリ」）は、利用者の個人情報および利用データを一切収集しません。

本アプリはネットワーク通信を行いません。計測結果・カード名・写真を含むすべてのデータは、 利用者の端末内にのみ保存され、外部のサーバーや第三者へ送信されることはありません。

収集しない情報

本アプリは以下の情報を 取得も送信もしません。

  • 氏名・メールアドレス・電話番号などの個人を識別できる情報
  • 端末の識別子（IDFA / 広告 ID / IMEI 等）
  • 位置情報
  • 連絡先・カレンダー・通話履歴などの端末内の他アプリのデータ
  • アプリの利用状況・クラッシュログ・アクセス解析などの統計情報

本アプリには解析 SDK・広告 SDK を一切組み込んでいません。

Android 版では、通信を行わないことを担保するため、アプリの権限として INTERNET を宣言していません。

端末内に保存する情報

以下は本アプリの機能のために、利用者の端末内にのみ保存されます。

保存するもの用途
カードの名前・アクセントカラー・並び順・グループ構成計測画面の構成を再現するため
計測状態（開始時刻・累積時間・ラップ）アプリを閉じても計測を継続・復元するため
保存データ（計測結果のスナップショットとラベル）過去の計測結果を後から参照するため
テンプレート（カード構成のひな型）カード構成を繰り返し使うため
設定値（言語・テーマ・画面消灯・ハプティクス・操作音）設定を次回起動時に引き継ぐため
写真（リッチ画面でカードに設定した画像）カードの識別を容易にするため

これらはアプリのアンインストールによって端末から削除されます。

なお本アプリは、Android の自動バックアップおよび端末間データ転送の対象からこれらのデータを 除外しています（allowBackup="false" および dataExtractionRules）。機種変更時にデータは 引き継がれません。

カメラおよび写真ライブラリの利用

リッチ画面でカードに写真を設定する場合に限り、カメラまたは写真ライブラリへのアクセス許可を 求めます。許可を求めるのは利用者が写真設定の操作を行ったときのみで、起動時には求めません。

取得した画像は端末内のアプリ領域にのみ保存され、外部へ送信されることはありません。 許可を拒否した場合でも、写真機能以外はすべて利用できます。

第三者への提供

本アプリはデータを収集しないため、第三者へ提供する情報はありません。

データの削除

利用者は以下の方法でデータを削除できます。

  • 個別のカード・保存データ・テンプレートを画面上から削除する
  • 設定画面の「全データを削除」ですべての計測データ・保存データ・テンプレートを削除する
  • 本アプリをアンインストールする（端末内のすべてのデータが削除されます）

子どものプライバシー

本アプリは年齢に関わらず利用できますが、いかなる利用者からも個人情報を収集しません。

本ポリシーの変更

本ポリシーを変更する場合は、本ページの内容を更新し、最終更新日を改めます。 重要な変更がある場合はアプリの更新情報でお知らせします。
