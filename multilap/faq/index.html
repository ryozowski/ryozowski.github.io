基本操作

カードを追加するには?

カードリストの最後にある「+」をタップすると名前入力が開き、OK で 1 枚追加されます。「続けて追加」を ON にしたまま OK すると、入力欄が空のまま再表示されて続けて追加できます。カードは 1 画面あたり 50 枚までです。

Start / Stop / Lap / Reset の違いは?

Start で計測を開始します。Stop でいったん停止し、もう一度 Start を押すと停止した続きから再開します。Lap は進行中の区間をその場で確定して、すぐ次の区間の計測を始めます。Reset はラップと時間をすべて消して初期状態に戻します。

使い方で見る →

カードの名前や色を変えるには?

カード上の名前をタップすると名前を変更できます（6 文字まで）。色は Total タイムをタップしてカード詳細を開き、右上のカラーアイコンから 16 色のプリセットを選んでください。

一括操作

全員を同時にスタートするには?

画面上部の一括操作バーの「一括 Start」を使います。タップした瞬間の時刻を共通の起点にするため、対象カードの計測開始時刻は完全に一致します。対象は初期状態と停止中のカードで、計測中のカードには影響しません。

使い方で見る →

一括ボタンが押せないのはなぜ?

一括ボタンは対象のカードが 0 件のときに非活性になります。一括 Stop と一括 Lap は計測中のカード、一括 Start は初期状態と停止中のカード、一括 Reset は停止中のカードだけが対象です。一括 Reset のみ確認ダイアログが出ます。

使い方で見る →

チームごとにまとめて操作できますか?

できます。カードを長押しして別のカードの上に 0.5 秒ほど重ねるとグループになります。Edit モードで複数選んで「グループ化」でもまとめられます。グループの見出しにある Start / Stop / Lap / Reset は、そのグループのカードだけに効きます。見出しの名前をタップすると、グループの名前・色・目標ラップ数を変えられます。

使い方で見る →

グループを解除するには?

カードを長押しして、グループの外にあるカードの位置まで運んで（重ねずに）離してください。Edit モードで選んで「グループから外す」でも構いません。中身が 0 枚になったグループは自動で消えます。カードも計測中のタイムも失われず、計測中でもグループの出し入れはできます。

ラップ

「現在ラップ」とは?

Start と同時に Lap1 が現在ラップとして始まります。まだ Lap で確定していない進行中の区間のことで、Stop しても確定しません（確定するのは Lap を押したときだけです）。Total・ラップ数・Avg・書き出したファイルには、この現在ラップが常に含まれます。

使い方で見る →

ラップの緑と赤は何を表していますか?

緑が最速ラップ、赤が最遅ラップです。判定の対象は Lap で確定したラップだけで、確定ラップが 2 本以上そろってから色が付きます。現在ラップは対象外です。同じタイムが複数あるときは、該当するすべてのラップに色が付きます。

使い方で見る →

事前に走る周回数を決めておけますか?

できます。一括操作バーの旗ボタンから目標ラップ数を登録すると、その画面の全カードに「2/5」のように 現在のラップ数と目標が表示されます。カードごとに変えたいときは、カード詳細の旗アイコンから そのカードだけの目標を設定できます。目標に達するとバッジが緑になりますが、計測は止まりません。超えたぶんも「7/5」のように表示し続け、Lap も Stop もこれまでどおり使えます。

使い方で見る →

ラップは何本まで記録できますか?

1 カードあたり 999 本（現在ラップを含む）です。上限に達すると Lap ボタンだけが無効になり、計測はそのまま続きます。

画面とテンプレート

標準・ミニ・リッチの違いは?

標準は 1 列の見やすいカード、ミニは 2 列で一覧性を優先、リッチは写真付きのカードです。カードは画面ごとに独立していて、それぞれ 50 枚まで持てます。標準画面で追加したカードはミニ画面には現れません。

使い方で見る →

テンプレートは何に使いますか?

よく使うカード構成（名前・色・並び順・グループ分け）をひな型として保存し、次回そのまま呼び出せます。画面種別に属さないので、標準画面で保存した構成をミニ画面から呼び出せます。呼び出すと表示中の画面のカードとラップはすべて削除されて置き換わるので、必要な計測結果は先に保存しておいてください。目標ラップ数はひな型には含まれません。

保存と共有

計測結果を残すには?

共有アイコンから「データを保存」を選ぶと、その時点のカード名・色・ラップ・Total が端末内に保存されます。ラベルの初期値は保存日時ですが、その場で書き換えられます。保存しても計測は止まりません。保存したデータは 設定 > 保存データ一覧 から見返せます。

使い方で見る →

CSV や TXT で書き出すには?

共有アイコンから「CSVで共有」「TXTで共有」「テキストをコピー」を選びます。CSV は Excel などの表計算ソフト向け、TXT とコピーはそのまま読める形式です。いずれも出力時点の現在ラップを最終ラップとして含みます。

Tips・こまったとき

他のアプリに切り替えたり画面を消しても大丈夫?

問題ありません。計測は開始時刻からの実時間で計算しているので、バックグラウンドでも画面ロック中でも正確に進みます。アプリが OS に終了された場合も、次の起動時に実時刻をもとに復元します。ただし端末の日時を手動で変更すると計測値がずれます。

計測中に画面が消えてしまいます

設定の「計測中は画面を消灯しない」を ON にしてください。いずれかのカードが計測中の間だけ画面の消灯を抑止し、全カードが止まると解除されます（計測自体は画面が消えても続きます）。

表示が 00:00.00 に戻ってしまいました

表示できる上限は 99:59.59 です。100 時間を超えると表示と出力の値だけが 00:00.00 に戻り、計測自体はそのまま続いています。

カード名に記号やスペースが入れられません

カード名に使えるのは、ひらがな・カタカナ・漢字・長音「ー」・英字・数字だけです。記号やスペース、絵文字は入力した時点で取り除かれます。長さは 6 文字までです。

全部やり直したい

設定の「全データを削除」で、3 画面すべてのカード・ラップ・保存データ・写真を消せます。設定の内容は残ります。この操作は取り消せません。

データとプライバシー

計測データはどこに保存されますか?

すべて端末の中に保存されます。本アプリはネットワーク通信を行わず、計測結果・カード名・写真を外部のサーバーへ送ることはありません。詳しくはプライバシーポリシーをご覧ください。

機種変更したらデータは引き継がれますか?

Android では引き継がれません。自動バックアップと端末間のデータ転送の対象から外しているためです。iOS では、端末のバックアップ（iCloud バックアップなど）を利用していれば、復元やクイックスタートで新しい端末に引き継がれます。確実に残したい記録は、事前に CSV やテキストで書き出して保管してください。

電波の届かない場所でも使えますか?

アプリの機能はすべて通信なしで使えます。ただし、設定画面から開く「使い方」「よくある質問」「利用規約」「プライバシーポリシー」はこの Web サイトのページなので、表示には通信が必要です。グラウンドなどで見たいときは、事前に一度開いておくと安心です。

アカウント登録は必要ですか?

必要ありません。インストールしてすぐに使えます。本アプリは利用者のアカウント情報を扱いません。
