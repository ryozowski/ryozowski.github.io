How to use

使い方

下の画面は、アプリと同じ動きをするデモです。緑の案内に沿ってタップすると、計測から記録の確認・共有までの基本の流れを 1 分ほどで体験できます。

触って覚える 6 ステップ

進み具合0 / 6
  1. 太郎さんの「Start」をタップ計測が始まります。Start と同時に Lap1 が「現在ラップ」として動き出します。
  2. 「Lap」を 2 回タップ押した瞬間に区間が確定し、すぐ次のラップが始まります。バッジの数字が今走っている周回です。
  3. 上の「一括 Start」をタップまだ始まっていない花子さん・健太さんが、同じ瞬間に一斉にスタートします。計測中の太郎さんには影響しません。
  4. 太郎さんのタイムをタップカード詳細が開きます。確定したラップの最速が緑・最遅が赤で表示され、Avg も分かります。
  5. 左上の「<」で戻る詳細を見ている間も計測は止まりません。戻るとタイムはそのまま進んでいます。
  6. 右上の共有アイコンをタップデータを保存・テキストをコピー・CSV / TXT で共有を選べます。現在ラップも含めて書き出されます。
おつかれさまでした。これで基本の流れはひととおりです。Stop・Reset・一括 Lap なども自由に試してみてください。

The card

カードの見かた

1 人ぶんのストップウォッチが 1 枚のカードです。カードは画面の一番下の「+」から追加します。

1太郎
2
03:42.18
33/501:12.40
4

カードを左へスワイプすると削除、長押しでドラッグすると並べ替えができます。

  1. 名前 — タップで名前を変更（6 文字まで）。
  2. Total — 計測開始からの合計タイム。タップするとカード詳細へ。計測は止まりません。
  3. 現在ラップ — バッジは今の周回数、右は今のラップのタイム。目標があると 3/5 のように表示。
  4. ボタン — 左は Start / Stop、右は Lap（計測中）/ Reset（停止中）。

States

3 つの状態とボタン

カードは「初期状態」「計測中」「停止」のどれかです。状態に合わせてボタンが入れ替わります。

初期状態
00:00.00 のまま。Start だけ押せます
計測中
Stop で一時停止、Lap でラップを確定
停止
Start で続きから再開、Reset で初期状態へ
  • Start 計測開始と同時に Lap1 が始まる
  • Lap 区間を確定して次のラップへ
  • Stop 一時停止（ラップは確定しない）
  • Start 停止した続きから再開
  • Reset ラップと時間をすべて消す（確認なし）

まだ確定していない進行中の区間を「現在ラップ」と呼びます。Total・ラップ数・Avg・書き出しには、現在ラップも常に含まれます。

Card detail

カード詳細でラップを見る

タイムをタップすると開きます。ラップを振り返ったり、色や目標を変えたりする画面です（計測ボタンはありません）。

  1. 最速は緑・最遅は赤 — 確定ラップが 2 本以上そろうと色が付きます。同タイムはすべてに付きます。
  2. ●の行が現在ラップ — 進行中の区間。最速・最遅の判定には入りません。
  3. 右上のアイコン — 旗はこのカードだけの目標、パレットは 16 色の色選び、共有はこのカードだけの書き出し。

Groups

グループでチームごとに操作する

カードをまとめると、見出しの Start / Stop / Lap / Reset がそのグループのカードだけに効きます。計測中でもまとめたり外したりできます。

▼1組(2)StartStopLapReset
太郎
01:45.10
200:34.02
花子
01:43.88
200:33.15
健太
00:00.00
100:00.00
  1. カードを長押しして、別のカードの上に 0.5 秒ほど重ねて離すとグループに。Edit で複数選んで「グループ化」でも作れます。
  2. 見出しのボタンはグループ内のカードだけが対象。対象の決まり方は一括操作と同じです。
  3. グループ名をタップで名前・色・目標ラップ数を設定。▼で折りたたみ。
  4. グループの外へ運んで離すと外れます。0 枚になったグループは自動で消えます。

Target laps

目標ラップ数を決めておく

一括操作バーの旗ボタンで「何周走るか」を登録すると、カードのバッジが「周回 / 目標」になります。

太郎
05:16.73
5/500:31.06
2/5走行中→5/5最終周で緑に→7/5超えても表示

目標に達しても計測は止まりません。Lap も Stop もこれまでどおり使えます。カード詳細の旗でカードごと、グループ設定でグループごとに変えられます（カード → グループ → 画面の順に優先）。

Templates

メンバー構成をテンプレートに

よく使うカードの名前・色・並び順・グループ分けを保存して、次回そのまま呼び出せます。標準で保存してミニで呼び出す、といった使い方もできます。

⋯

呼び出すと、表示中の画面のカードとラップはすべて消えて置き換わります。残したい記録は先に保存してください。目標ラップ数はテンプレートに含まれません。

Save & share

結果を保存・共有する

共有アイコンから、その場で記録を残せます。保存や書き出しをしても計測は止まりません。

  • データを保存 — 端末内に記録を保存。あとで 設定 > 保存データ一覧 から見返せます。ラベルは保存日時が初期値です。
  • テキストをコピー — そのまま読める形でクリップボードへ。LINE やメモに貼り付けられます。
  • CSVで共有 — Excel などの表計算ソフト向け。
  • TXTで共有 — テキストファイルとして共有。

メイン画面の共有はその画面の全カード、カード詳細の共有はそのカードだけが対象です。

Settings

知っておくと便利な設定

計測中は画面を消灯しない

どれかのカードが計測中のあいだだけ画面を点けたままにします（初期値 ON）。

ハプティクス・操作音

ボタンを押したときの振動と音。音は初期値 OFF です。

言語・テーマ

端末の設定に合わせるか、日本語 / English、ライト / ダークを選べます。このサイトもアプリの設定に合わせて表示されます。

全データを削除

3 画面すべてのカード・ラップ・保存データ・写真を消します。設定は残ります。

アプリを切り替えても、画面をロックしても、計測は実際の時刻から計算しているので正確に進みます。
